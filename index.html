1เกี่ยวกับนโยบายนี้

นโยบายนี้อธิบายว่าผู้พัฒนาแอป Stock & AI Trading (“เรา”) เก็บ ใช้ เปิดเผย และดูแลข้อมูลของคุณอย่างไร เมื่อคุณใช้แอป Stock & AI Trading บน Android และเซิร์ฟเวอร์ API ที่แอปเชื่อมต่อ (รวมเรียกว่า “บริการ”) โดยเราเป็นผู้ควบคุมข้อมูลส่วนบุคคลตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

บริการนี้ให้ข้อมูลการวิเคราะห์ทางเทคนิคเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน และไม่มีการซื้อขายหลักทรัพย์หรือการชำระเงินในแอป

2ข้อมูลที่เราเก็บ

เราเก็บเฉพาะข้อมูลที่จำเป็นต่อการให้บริการ ดังนี้

  • รหัสการติดตั้ง (Install ID)รหัสสุ่มที่ขึ้นต้นด้วย “android-” ซึ่งแอปสร้างขึ้นเมื่อเปิดใช้งานครั้งแรก ไม่ใช่ IMEI หมายเลขโทรศัพท์ หรือ Advertising ID และไม่ผูกกับตัวตนจริงของคุณ แอปส่งรหัสนี้ไปกับคำขอเกี่ยวกับ Watchlist และตอนลงทะเบียนรับการแจ้งเตือน
  • Watchlist ของคุณสัญลักษณ์หุ้นและตลาดที่คุณเพิ่ม (สูงสุด 100 ตัว) เก็บบนเซิร์ฟเวอร์โดยผูกกับรหัสการติดตั้ง
  • ข้อมูลการแจ้งเตือนโทเคน Firebase Cloud Messaging (FCM), รหัสการติดตั้ง, ยี่ห้อและรุ่นของเครื่อง (เช่น Samsung SM-S921B), แพลตฟอร์ม, ภาษา, ประเภทการแจ้งเตือนที่รับ, สถานะเปิด/ปิด และเวลาที่ลงทะเบียนหรืออัปเดต
  • คำขอและล็อกของเซิร์ฟเวอร์เมื่อแอปเรียกเซิร์ฟเวอร์ เราบันทึกหมายเลข IP, เวลา, เส้นทางของคำขอ (ซึ่งรวมสัญลักษณ์หุ้นที่คุณเปิดดู), วิธีการเรียก และผลลัพธ์ เว็บเซิร์ฟเวอร์ที่อยู่ด้านหน้า API ยังบันทึกล็อกการเข้าถึงมาตรฐาน เช่น หมายเลข IP, URL, user agent และ header ของคำขอ โดยรหัสการติดตั้งและ API key จะถูกปิดทับก่อนบันทึกทุกครั้ง
  • ค่าที่ใช้คำนวณตัวเลขในหน้าจัดการความเสี่ยง (เงินลงทุน, ราคาเข้า, เปอร์เซ็นต์ตัดขาดทุน/ทำกำไร และความเสี่ยงต่อไม้) และสัญลักษณ์หุ้นที่คำนวณ (เพื่อให้คริปโตคิดเป็นเศษเหรียญได้) ถูกส่งไปคำนวณแล้วส่งผลกลับทันที เราไม่บันทึกค่าเหล่านี้
  • ประวัติการแจ้งเตือนที่ส่งรหัสการติดตั้งที่ได้รับการแจ้งเตือน, หุ้น, ประเภทการแจ้งเตือน, ข้อความ และเวลา
  • บันทึกการเปลี่ยนแปลง Watchlistรหัสการติดตั้ง, การกระทำ (เพิ่ม ลบ ล้าง หรือโหลดชุดหุ้นพรีเซ็ต), สัญลักษณ์หุ้น และเวลา
  • ข้อมูลที่อยู่ในเครื่องเท่านั้นธีม, ภาษา, รหัสการติดตั้ง, การยอมรับข้อจำกัดความรับผิดชอบ (เวอร์ชันและเวลา), ประกาศในแอปที่คุณกดปิดแล้ว, เวอร์ชันใหม่ที่คุณเลือกยังไม่อัปเดต (เวอร์ชันและเวลา เพื่อไม่ถามซ้ำทุกครั้งที่เปิดแอป) และจำนวนวันที่เปิดแอปกับเวลาล่าสุดที่แอปขอแสดงการ์ดให้คะแนนของ Google Play (เพื่อไม่ถามเร็วหรือบ่อยเกินไป) เก็บในพื้นที่ของแอปบนเครื่องคุณ โดยรหัสการติดตั้งจะไม่ถูกสำรองไปยังบัญชี Google หรือย้ายไปเครื่องใหม่

3ข้อมูลที่เราไม่เก็บ

  • ชื่อ อีเมล เบอร์โทรศัพท์ หรือบัญชีผู้ใช้และรหัสผ่าน
  • ตำแหน่งที่ตั้ง (GPS) รายชื่อติดต่อ รูปภาพ ไฟล์ กล้อง หรือไมโครโฟน — แอปไม่ขอสิทธิ์เหล่านี้ และเราไม่ใช้หมายเลข IP เพื่อระบุตำแหน่งของคุณ
  • Advertising ID หรือข้อมูลเพื่อการโฆษณา — แอปไม่แสดงโฆษณา และไม่มี SDK โฆษณา วิเคราะห์ หรือติดตามผู้ใช้
  • ข้อมูลบัญชีหลักทรัพย์ บัญชีธนาคาร หรือบัตร — แอปไม่มีการซื้อขายหรือการชำระเงิน

เราอาจโปรโมตแอปนี้บน Google Play หรือช่องทางโฆษณาอื่น แต่ไม่ส่งข้อมูลใดจากแอปหรือเซิร์ฟเวอร์ของเราไปยังแพลตฟอร์มโฆษณา

4เราใช้ข้อมูลอย่างไร

  • ให้บริการตามที่คุณขอ: แสดงราคา อินดิเคเตอร์ และผลวิเคราะห์ AI เก็บ Watchlist ของเครื่องคุณ และคำนวณความเสี่ยง
  • ส่งการแจ้งเตือนเกี่ยวกับหุ้นที่คุณติดตาม ในภาษาที่คุณเลือก
  • รักษาความปลอดภัย: ตรวจสอบ API key จำกัดจำนวนคำขอต่อหมายเลข IP และป้องกันการใช้งานในทางที่ผิด
  • ตรวจหาและแก้ไขข้อผิดพลาด และดูแลให้ระบบทำงานได้ดี
  • นับสถิติแบบรวม เช่น จำนวนเครื่องที่ติดตามหุ้นแต่ละตัว เพื่อจัดลำดับการสแกนสัญญาณ

ผลวิเคราะห์ AI คำนวณจากข้อมูลราคาตลาดเท่านั้น ไม่ได้ใช้ข้อมูลส่วนตัวของคุณ และเราไม่ใช้ข้อมูลของคุณเพื่อการโฆษณา การทำโปรไฟล์ หรือการตัดสินใจอัตโนมัติที่มีผลต่อคุณ

5ฐานทางกฎหมายในการประมวลผล

  • การให้บริการตามคำขอของคุณWatchlist การวิเคราะห์ และการคำนวณ
  • ประโยชน์โดยชอบด้วยกฎหมายล็อกของเซิร์ฟเวอร์เพื่อความปลอดภัย การป้องกันการใช้งานในทางที่ผิด และการแก้ไขปัญหา
  • ความยินยอมการแจ้งเตือน ซึ่งคุณอนุญาตผ่านสิทธิ์การแจ้งเตือนของ Android และถอนได้ทุกเมื่อในการตั้งค่าของเครื่อง
  • หน้าที่ตามกฎหมายเมื่อกฎหมายหรือหน่วยงานรัฐที่มีอำนาจกำหนดให้เราเก็บหรือเปิดเผยข้อมูล

6การเปิดเผยข้อมูล

เราไม่ขายหรือให้เช่าข้อมูลของคุณ และไม่แบ่งปันเพื่อการโฆษณา เราเปิดเผยข้อมูลเฉพาะกรณีต่อไปนี้

  • Google Firebase Cloud Messagingใช้ส่งการแจ้งเตือนไปยังเครื่องของคุณ Firebase SDK ในแอปสร้าง Firebase installation ID และส่งให้ Google เพื่อออกโทเคน FCM จากนั้น Google ประมวลผลโทเคนและเนื้อหาการแจ้งเตือนตามนโยบายของ Google (นโยบายความเป็นส่วนตัวของ Google, ความเป็นส่วนตัวและความปลอดภัยใน Firebase)
  • Google Play (อัปเดตในแอป)แอปถามแอป Google Play Store บนเครื่องของคุณว่ามีเวอร์ชันใหม่หรือไม่ และให้ Google Play ดาวน์โหลดและติดตั้งเมื่อคุณกดอัปเดต Google Play ใช้ข้อมูลอุปกรณ์และเวอร์ชันของแอปเพื่อตรวจหาอัปเดตตามนโยบายของ Google (การเก็บข้อมูลของ Play In-App Updates) — แอปไม่ส่งข้อมูลนี้มาที่เซิร์ฟเวอร์ของเรา
  • Google Play (รีวิวในแอป)หลังคุณใช้แอปไปสักพัก แอปอาจขอให้ Google Play แสดงการ์ดให้คะแนน คะแนนและข้อความที่คุณกรอกส่งตรงถึง Google Play และแสดงเป็นรีวิวสาธารณะบน Google Play ตามนโยบายของ Google (การเก็บข้อมูลของ Play In-App Review) คุณลบรีวิวได้จากบัญชี Google Play ของคุณ — แอปไม่รู้ว่าคุณให้คะแนนเท่าไร และไม่ส่งข้อมูลนี้มาที่เซิร์ฟเวอร์ของเรา
  • ผู้ให้บริการเซิร์ฟเวอร์เซิร์ฟเวอร์ของเราทำงานบนคลาวด์ที่เราเช่า ผู้ให้บริการจัดเก็บข้อมูลแทนเราตามเงื่อนไขการให้บริการ
  • แหล่งข้อมูลราคาเซิร์ฟเวอร์ของเราดึงราคาจากแหล่งข้อมูลสาธารณะ เช่น Yahoo Finance ด้วยสัญลักษณ์หุ้นเท่านั้น โดยไม่ส่งข้อมูลใด ๆ ของคุณไปด้วย
  • หน่วยงานตามกฎหมายเมื่อกฎหมาย คำสั่งศาล หรือหน่วยงานรัฐที่มีอำนาจกำหนด หรือเพื่อปกป้องสิทธิและความปลอดภัยของผู้ใช้และบริการ

7การส่งข้อมูลไปต่างประเทศ

Google และผู้ให้บริการเซิร์ฟเวอร์อาจประมวลผลข้อมูลในศูนย์ข้อมูลนอกประเทศไทย เราเลือกใช้ผู้ให้บริการที่มีมาตรฐานการคุ้มครองข้อมูลที่เหมาะสม และส่งข้อมูลเท่าที่จำเป็นต่อการให้บริการเท่านั้น

8ระยะเวลาเก็บข้อมูล

  • Watchlistจนกว่าคุณจะกด “ล้างทั้งหมด” ในแอปหรือขอให้ลบ หากถอนการติดตั้งโดยไม่ล้างก่อน รายการจะค้างอยู่บนเซิร์ฟเวอร์โดยผูกกับรหัสที่ไม่มีเครื่องใดใช้แล้ว
  • ข้อมูลการแจ้งเตือนจนกว่าจะถอนการติดตั้งแอป (โทเคนจะหมดอายุ และถูกลบอัตโนมัติเมื่อระบบส่งการแจ้งเตือนครั้งถัดไปไม่สำเร็จ) หรือจนกว่าคุณจะขอให้ลบ
  • ล็อกคำขอ API และประวัติการแจ้งเตือนที่ส่ง30 วัน แล้วลบอัตโนมัติ
  • บันทึกการเปลี่ยนแปลง Watchlistเก็บไว้เพื่อตรวจสอบความปลอดภัยของระบบ และลบเมื่อคุณขอ
  • ล็อกการเข้าถึงของเว็บเซิร์ฟเวอร์และล็อกการทำงานของเซิร์ฟเวอร์ไม่เกิน 30 MB ต่อส่วนของเซิร์ฟเวอร์ เมื่อเต็มแล้ว รายการที่เก่าที่สุดจะถูกลบอัตโนมัติ ล็อกเหล่านี้มีหมายเลข IP, เวลา และ URL ของคำขอ แต่ไม่มีรหัสการติดตั้งหรือ API key
  • ตัวนับจำนวนคำขอต่อ IP60 วินาที ในหน่วยความจำเท่านั้น ไม่บันทึกลงดิสก์
  • ข้อมูลในเครื่องจนกว่าคุณจะล้างข้อมูลแอปหรือถอนการติดตั้ง

9การรักษาความปลอดภัย

  • ข้อมูลระหว่างแอปกับเซิร์ฟเวอร์เข้ารหัสด้วย HTTPS (TLS) และแอปเวอร์ชันเผยแพร่เชื่อมต่อผ่าน HTTPS เท่านั้น
  • ทุกคำขอต้องมี API key และถูกจำกัดจำนวนต่อหมายเลข IP
  • แต่ละเครื่องเห็นและแก้ไขได้เฉพาะ Watchlist ของตนเอง
  • ฟังก์ชันของผู้ดูแลระบบต้องใช้กุญแจแยกที่ไม่ได้อยู่ในแอป และแสดงโทเคน FCM แบบปิดบางส่วน
  • จำกัดการเข้าถึงเซิร์ฟเวอร์และข้อมูลเฉพาะผู้พัฒนา

1About this policy

This policy explains how the developer of Stock & AI Trading (“we”) collects, uses, shares and protects your information when you use the Stock & AI Trading app for Android and the API server it connects to (together, the “Service”). We are the data controller under Thailand's Personal Data Protection Act B.E. 2562 (2019) (PDPA).

The Service provides technical-analysis information for education. It is not investment advice, and there is no trading or payment inside the app.

2Information we collect

We collect only what the Service needs in order to work:

  • Install IDA random identifier starting with “android-”, created by the app on first launch. It is not your IMEI, phone number or advertising ID, and it is not tied to your real identity. The app sends it with watchlist requests and when it registers for alerts.
  • Your watchlistThe symbols and markets you add (up to 100), stored on our server under your install ID.
  • Alert registrationYour Firebase Cloud Messaging (FCM) token, install ID, device manufacturer and model (e.g. Samsung SM-S921B), platform, language, the alert types you receive, whether alerts are on, and when this was registered or last updated.
  • Requests and server logsWhen the app calls our server we log the IP address, time, request path (which includes the symbol you viewed), method and result. The web server in front of the API also keeps a standard access log with the IP address, URL, user agent and request headers, with your install ID and the API key always blanked out before it is written.
  • Calculator inputsThe numbers on the risk screen (capital, entry price, stop-loss and take-profit percentages, risk per trade) and the symbol they are for (so crypto can be sized in fractions of a coin) are sent to be calculated and the result comes straight back. We do not store these inputs.
  • Alerts sentWhich install ID received an alert, for which stock, the alert type, its text and the time.
  • Watchlist change logThe install ID, the action (add, remove, clear or load a preset), the symbol and the time.
  • Stored only on your phoneYour theme, language, install ID, your acceptance of the disclaimer (version and time), the in-app notice you closed, a new version you chose not to install yet (version and time, so the app doesn't ask on every launch) and how many days you have opened the app and when it last offered Google Play's rating card (so it doesn't ask too soon or too often) are kept in the app's storage on your phone. The install ID is left out of Google backups and device transfers.

3What we do not collect

  • Your name, email address, phone number, or any account or password
  • Location (GPS), contacts, photos, files, camera or microphone — the app does not ask for these permissions, and we do not use your IP address to locate you
  • Your advertising ID or any advertising data — the app shows no ads and has no ad, analytics or tracking SDK
  • Brokerage, bank or card details — the app has no trading or payments

We may promote this app on Google Play or other advertising channels, but we never send information from the app or our server to an advertising platform.

4How we use information

  • To provide what you ask for: prices, indicators and AI analysis, your install's watchlist, and risk calculations
  • To send alerts about the stocks you watch, in the language you chose
  • To keep the Service secure: checking the API key, limiting requests per IP address and preventing abuse
  • To find and fix errors and keep the Service running well
  • To count in aggregate, e.g. how many installs watch each stock, to decide which stocks to scan first

AI analysis is computed from market price data only, never from your personal information, and we do not use your information for advertising, profiling or automated decisions that affect you.

5Legal basis for processing

  • Providing the Service you requestYour watchlist, analysis and calculations
  • Legitimate interestsServer logs for security, abuse prevention and troubleshooting
  • ConsentAlerts, which you allow through Android's notification permission and can withdraw at any time in your phone's settings
  • Legal obligationsWhen a law or a competent authority requires us to keep or disclose information

6Sharing

We do not sell or rent your information, or share it for advertising. We share it only as follows:

  • Google Firebase Cloud MessagingDelivers alerts to your phone. The Firebase SDK in the app creates a Firebase installation ID and sends it to Google to issue the FCM token; Google then processes the token and the alert content under its own policies (Google Privacy Policy, Privacy and Security in Firebase).
  • Google Play (in-app updates)The app asks the Google Play Store app on your phone whether a newer version is out, and has Google Play download and install it when you choose to update. Google Play uses device information and the app's version to check for updates, under Google's policies (Play In-App Updates data collection) — the app sends none of this to our server.
  • Google Play (in-app reviews)After you have used the app for a while, it may ask Google Play to show its rating card. The rating and text you enter go straight to Google Play and appear as a public review there, under Google's policies (Play In-App Review data collection); you can delete your review from your Google Play account. The app never learns what rating you gave, and none of this is sent to our server.
  • Hosting providerOur server runs on cloud infrastructure we rent, and the provider stores data on our behalf under its service terms.
  • Market data sourcesOur server fetches prices from public sources such as Yahoo Finance using only the stock symbol, without any of your information.
  • AuthoritiesWhen required by law, a court order or a competent authority, or to protect the rights and safety of users and the Service.

7International transfers

Google and our hosting provider may process information in data centres outside Thailand. We use providers with appropriate data-protection standards and send only what the Service needs.

8How long we keep it

  • WatchlistUntil you tap “Clear All” in the app or ask us to delete it. If you uninstall without clearing it, the list stays on the server under an ID that no device uses any more.
  • Alert registrationUntil you uninstall the app (the token expires and is removed automatically the next time an alert cannot be delivered), or until you ask us to delete it.
  • API request logs and alerts sent30 days, then deleted automatically.
  • Watchlist change logKept for security auditing; deleted when you ask.
  • Web server access logs and the server's process logsUp to 30 MB for each part of the server; once full, the oldest entries are deleted automatically. They hold the IP address, time and URL of requests, but never your install ID or the API key.
  • Per-IP request counters60 seconds, in memory only; never written to disk.
  • Data on your phoneUntil you clear the app's data or uninstall it.

9Security

  • Data between the app and our server is encrypted with HTTPS (TLS), and release builds of the app connect only over HTTPS
  • Every request needs an API key, and requests are rate-limited per IP address
  • Each install can see and change only its own watchlist
  • Admin functions need a separate key that is not in the app, and they show FCM tokens masked
  • Access to the server and its data is limited to the developer

No system is 100% secure. If a personal data breach puts your rights at risk, we will notify Thailand's Personal Data Protection Committee office, and you, as the law requires.

10Your rights

Under the PDPA you have the right to:

  • Access your information and get a copy of it
  • Have it corrected and kept up to date
  • Have it deleted, destroyed or anonymised
  • Have its use restricted
  • Object to its collection, use or disclosure
  • Receive it in a machine-readable format or have it sent to another controller
  • Withdraw your consent at any time, without affecting processing done before
  • Complain to Thailand's Office of the Personal Data Protection Committee (PDPC)

Email your request to the address under “Contact us”, with your install ID (in the app: ⚙️ Settings → Privacy), since we hold nothing else that tells us which data is yours. We reply within 30 days.

  • Data on your phoneClear the app's data, or uninstall it.

Clear your watchlist before uninstalling: once the app is gone, so is the install ID, and we can no longer tell which data is yours.
